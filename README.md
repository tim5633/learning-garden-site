# Learning Garden — Public Site

This repository contains the static GitHub Pages artifact for the public part
of the Learning Garden knowledge base.

Only notes explicitly reviewed and marked with `source_scope: public` are
exported here. It intentionally contains no raw source files, company notes,
personal capture data, secrets, or private repository history.

The editable workspace and export policy live in the private
[`learning-garden`](https://github.com/tim5633/learning-garden) repository.
